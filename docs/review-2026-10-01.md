# Review remediation — 2026-10-01

See [Review 2 remediation](review-2-2026-10-01.md) for the subsequent runtime changes and fresh verification.

The runtime fixes below are implemented locally and tested in the disposable
WordPress site at `http://127.0.0.1:18943/` (WordPress 7.1.2, PHP 8.5.9).

## Release status

`twig-bundle` now requires stable framework-bundle `^1.0.1`, kernel `^1.1` and
QA `^0.1`, with stable minimum stability. Its tested commit is
`f7e449e128` (short reference), published as `1.0.2`. Full bundle QA passed:
PHPCS, PHPStan and 5 PHPUnit tests / 15 assertions.

**Publication completed after user approval.** The branch and annotated tag were
pushed and [GitHub release 1.0.2](https://github.com/SymPress/twig-bundle/releases/tag/1.0.2)
was published. Packagist serves the same commit with stable dependency constraints.
A fresh, uncached Composer installation resolved the local theme and downloaded
twig-bundle 1.0.2 from GitHub through Packagist, without any local twig-bundle
repository or development-version alias. All production dependencies resolved to
stable releases. The theme and WordPress fixture now use their regular Composer
configuration; their lock files were updated from the public registry.

The [GitHub QA run](https://github.com/SymPress/twig-bundle/actions/runs/36875016019)
passed all three jobs. GitHub reported that the publishing account bypassed the
branch's PR/status-check requirements on the direct push; local QA passed before
publication, and the resulting remote QA run was verified afterwards. No repository
protection settings were changed.

The theme is now an independent Git repository. The baseline commit is
`95e96e2`; the remediation is committed separately and tagged `0.1.0`.
The theme is hosted in the private [SymPress/theme-starter repository](https://github.com/SymPress/theme-starter)
with its `main` branch and version tag. Existing changes in
framework-bundle and other sibling repositories were preserved.
